# 复现和判断 Workflow

## 1. 适用范围

本工作流用于处理需要验证真实性、稳定性、影响范围和处理优先级的问题。典型场景包括：

- 论文或实验结果复现。
- 产品缺陷、异常行为或用户反馈复现。
- 数据结果、模型输出或统计结论复核。
- 线上问题、环境差异或依赖变更排查。
- 合作者提交的新现象、新假设或新判断。

## 2. 总体流程

```text
任务录入 -> 信息澄清 -> 复现准备 -> 执行复现 -> 证据整理 -> 判断分析 -> 复核 -> 归档
```

每个阶段都要留下可追踪记录。记录的重点不是证明某个人对错，而是让下一位合作者能够理解：问题是什么、尝试了什么、看到了什么、为什么得出当前结论。

## 3. 角色

| 角色 | 责任 |
| --- | --- |
| 提出者 | 描述问题、提供背景、说明期望现象和实际现象。 |
| 复现者 | 搭建环境、执行步骤、记录结果和证据。 |
| 判断者 | 分析原因、影响范围、优先级和处理建议。 |
| 复核者 | 检查证据是否充分、结论是否过度推断。 |

同一个人可以承担多个角色，但判断和复核尽量分开。

## 4. 阶段一：任务录入

使用 `templates/intake.md` 创建任务。一个好任务至少包含：

- 背景：为什么要看这个问题。
- 观察：实际发生了什么。
- 期望：理论上应该发生什么。
- 范围：影响对象、版本、数据、时间窗口。
- 材料：链接、截图、日志、数据样例、代码版本。
- 成功标准：怎样算复现成功，怎样算判断完成。

录入完成后，把任务状态标为 `intake`。

## 5. 阶段二：信息澄清

复现前先检查信息是否足够。若缺少关键信息，不急着执行。

需要确认的问题：

- 是否有最小复现步骤。
- 是否知道运行环境、依赖版本和数据来源。
- 是否有明确的期望结果。
- 是否知道问题出现频率。
- 是否有可能涉及权限、隐私或敏感数据。

信息足够后，将状态改为 `ready-to-reproduce`。

## 6. 阶段三：复现准备

复现准备要尽量可重复：

- 固定代码版本、配置、数据版本和依赖版本。
- 记录操作系统、运行环境、账号权限和外部服务状态。
- 如果使用样例数据，说明样例如何构造。
- 如果不能共享原始数据，提供脱敏样例或数据摘要。
- 把复现命令、入口页面或操作路径写清楚。

推荐保存以下证据：

- 终端输出摘要。
- 关键截图。
- 日志片段。
- 输入数据样例。
- 输出结果文件。
- 环境信息。

## 7. 阶段四：执行复现

执行复现时按“最小路径优先”：

1. 按提出者提供的步骤执行一次。
2. 如果失败，补齐环境信息后再次执行。
3. 如果仍失败，缩小变量：版本、数据、账号、配置、时间窗口。
4. 记录每次尝试的输入、操作、结果和差异。

复现结果分为三类：

| 结果 | 判断 |
| --- | --- |
| 成功复现 | 现象在当前条件下成立。 |
| 部分复现 | 现象存在，但条件、程度或表现不同。 |
| 未复现 | 当前条件下没有观察到现象，不代表问题不存在。 |

## 8. 阶段五：证据整理

使用 `templates/reproduction-report.md` 记录复现报告。报告必须区分：

- 事实：直接观察到的结果。
- 条件：这些结果出现在哪些环境、版本、数据下。
- 尝试：做过哪些步骤。
- 限制：哪些条件没有覆盖。
- 附件：能支持判断的材料。

证据不足时，不进入强结论。可以标记为“需要更多信息”。

## 9. 阶段六：判断分析

使用 `templates/judgement-record.md` 输出判断。判断内容包括：

- 结论类型：确认问题、非问题、环境问题、数据问题、待定。
- 影响范围：用户、系统、数据、业务或研究结论。
- 严重程度：低、中、高、紧急。
- 置信度：低、中、高。
- 可能原因：必须标注证据来源。
- 建议动作：修复、继续观察、补充实验、关闭、升级处理。

判断时避免三种常见错误：

- 把偶然复现当作稳定规律。
- 把未复现当作问题不存在。
- 把合理猜测写成确定事实。

## 10. 阶段七：复核

复核者检查：

- 是否能根据报告重新执行关键步骤。
- 证据是否支持结论。
- 结论是否有过度推断。
- 是否遗漏明显变量。
- 是否需要补充测试、实验或用户确认。

复核通过后，任务可标记为 `resolved`。

## 11. 阶段八：归档

归档时保留：

- 最终复现报告。
- 最终判断记录。
- 关键证据或证据索引。
- 后续动作和责任人。
- 关闭原因。

如果后续发现新证据，应重新打开任务，而不是直接覆盖旧结论。

## 12. 质量标准

一份合格的复现和判断记录应满足：

- 合作者能复读问题背景。
- 合作者能知道复现是否成功，以及为什么。
- 合作者能看到证据链。
- 合作者能区分事实和推断。
- 合作者能接着做下一步。
